# GitHub Project Tasks

Create concise, implementation-sized issues.

Every task must include:
- Imperative title describing one outcome.
- Scope and relevant context.
- Testable acceptance criteria.
- Explicit out-of-scope items.
- Dependencies and references.
- Appropriate labels, priority, size, status, and parent issue.

Use observable behavior, not vague activities. Cover error, empty, security, accessibility, and data-integrity cases when relevant. Check for duplicates before creating. Split oversized or unrelated work. Never include secrets or private data.
